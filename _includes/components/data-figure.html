{%- comment -%} 交互式数据图表组件（数据来自仓库内的 CSV / JSON 文件，零外部依赖）。 用法：在 .md 帖子里顶格写一行 include 标签（不要缩进，也不要放进代码块）， 第一个参数是组件路径 components/data-figure.html，其余参数如下。 参数：id / src / type(timeline|line|bar|scatter|area) / label / x / y / series / sort / title / xlabel / ylabel / caption / height / legend type="timeline" 时：label=模型名列，x=总参数量列（单位十亿），y=激活参数量列（可空）， series=应用场景列；柱子按对数轴排布，MoE 用深浅两段表示激活/总参数量。 {%- endcomment -%} {%- assign df_src = include.src | relative_url -%} {%- assign df_height = include.height | default: 420 -%} {%- assign df_id = include.id | default: include.src | default: "figure" | slugify -%}
